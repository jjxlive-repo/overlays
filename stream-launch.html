Social Stream Ninja Dock
Aggregated chat + TTS relay. Pick a voice, then launch — the link is built fresh each time.
Two fixes vs. your original link, both confirmed against Social Stream Ninja's source (dock.html / tts.js): (1) swapped speech=en-GB for lang=en-GB — the speech param flips on a master "read every incoming message" fallback that would have spoken everything regardless of the . command or members-only setting; lang sets the same accent without that side effect. (2) dropped modtts — it restricts all TTS to moderator messages only (verified in source), which would have blocked members entirely rather than including mods. (3) added ttssources=youtube so SSN only ever speaks YouTube chat — TikTok already has its own TTS through Tikfinity, and this stops SSN from double-reading it.

Mods without a membership — dock.html's command gate checks channel membership only, never moderator status, and there's no URL parameter for it. Since comping isn't an option, use the Mod TTS Allowlist userscript below instead: it patches the dock's own message handler (client-side, in your browser) to stamp membership on names you add to a self-service list, so they pass the same gate a real paid member would.

Spin The Screen — Control
Tier floors, which of the nine results are enabled, penny spins and signature lifetimes — all written straight to the dock's own settings, live, no restart. Also previews any effect on the overlay without laying a brick in the supporter wall. Setup only; it is not a browser source.
🖐️
Gesture Engine
Watches your stream via screen capture and fires gesture-triggered events. Also feeds Spin The Screen: the head box its face-anchored effects track, the game's bucket rect for Ball Drop, the camera still Ball Drop freezes, and the Ball Guys collision geometry used by both Bomb Drop and the wheel's falling ball. Runs in desktop Chrome, NOT as a Studio source — it needs screen capture, which Studio cannot host. Optional: without it the wheel still works, using a fixed head anchor and its own bucket. Calibrate the three boxes (stream picture / camera strip / game area) after starting capture — the camera strip is what makes Ball Drop's freeze line up.
Overlay Source URLs (for TikTok Studio)
These load automatically once added as browser sources — you only need these to add or re-add one. Every URL uses the TikTok canvas fix: set Custom Resolution 1080×1392, then choose Stretch. Gesture Suite replaces the separate Feed Jamie, Spin the Screen, Bomb Drop, Gesture FX, and Follow Meter sources. Follow alerts are composited as the highest layer so they always appear above a spin. Remove or hide those five individual sources in TikTok Studio to prevent duplicate effects. Hand Feed stays separate because it owns and renders the camera feed itself; it is not driven by the Gesture Engine page.
